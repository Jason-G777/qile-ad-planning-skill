## 阅读与调用方式

- 月度文件保存全部入选项目的深度机制卡，不按行业归类，避免只在同品类里找参考。
- 根目录的《数英优秀案例机制库》按“创意问题”建立二级索引，用于实际 Brief 调用。
- 每次借鉴只拿走生成机制：事实如何被找到、品牌如何进入、媒介如何承担观点、用户为何愿意参与；不复制主题原句、故事外壳或视觉造型。
- 调用时必须重新回答当前品牌的创意母体、产品证据、代表性执行和转化承接，并通过换品牌测试。

## 字段说明

- **核心策略**：案例真正要解决的传播问题与品牌角色。
- **创意母体**：概念赖以生长的品牌 / 产品 / 人群 / 文化事实。
- **核心机关**：把事实变成可见、可讲、可参与传播的生成方式。
- **可复用问题**：适用于哪一类 Brief 卡点。
- **禁用边界**：缺少什么条件时不可照借。
