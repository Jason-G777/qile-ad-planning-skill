# 七楽自研广告创意策划Skill

陪广告人一起拆 Brief、找洞察、想创意、改方案。从一句标题到一场整合营销，少点套话，多点能直接拿去提案的内容。

## 能帮你做什么

- 接到 Brief，先理清到底要解决什么问题。
- 找消费者洞察、查案例，把参考变成适合当前品牌的新点子。
- 写 Campaign 主题、Slogan、TVC、达人脚本和 PPT 页面文案。
- 梳理媒介整合、小红书种草、传播节奏和到店转化。
- 看方案哪里没讲通，具体告诉你删什么、换什么、补什么。
- 搜公开网页和平台内容，分析评论、访谈等研究材料。

默认用中文，先给一个认真打磨的方向；需要发散时再展开。保留已经确认的内容，修改时不反复推倒重来。

## 安装到 WorkBuddy

下载仓库中的 `ad-planning-copilot-cn.workbuddy.zip`，在 WorkBuddy 的“添加技能 → 上传技能”中导入。新建对话，直接提交策划需求即可，也可点名调用 `ad-planning-copilot-cn`。

详细说明见 [安装说明](INSTALL-WORKBUDDY.md)。联网与部分研究功能需要本机具备对应工具，安装 Skill 不等于自动装好所有运行组件。

## 这份 Skill 从哪里来

核心是七楽策划工作区持续调整的身份设定、写作偏好、案例机制库与工作流程，并整合以下独立模块：

- `agent-reach`：联网搜索与内容读取。
- `genz-insight-radar`：年轻人话题与洞察。
- `songyue-insight`：消费者洞察判断。
- `songyue-marketingdx`：营销方案诊断。
- `planners-quali-box`：定性材料研究。

“自研”指本项目的整合、协作规范与工作流，不表示上述第三方模块为原创，也不代表原作者为本项目背书。
